### Built in public

**[mercury-works](https://github.com/SuryanshD/mercury-works)** — an autonomous AI creative agency.
One sentence of brand brief becomes a complete live brand: research, naming, design, illustration, a
voiceover radio ad, and a deployed site with checkout, with zero human edits. Shipped 11 real live
brand sites in an 8-hour buildathon. MIT. Built with [Piyush Rane](https://github.com/PiyushRane).

**[munshi](https://github.com/SuryanshD/munshi)** — a bilingual Hindi/English health-insurance claims
processor. Reads handwritten medical documents and produces a submittable claim packet, using a
two-model agreement check that abstains instead of guessing. A confidently wrong number on a medical
claim is worse than an empty one. Built with [Piyush Rane](https://github.com/PiyushRane).
